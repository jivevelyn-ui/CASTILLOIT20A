1. Briefly explain what your Java program does.
Ang akong java program kay nay tulo ka method nga nag represent sa tulo ka klase sa sorting algorithm nga bubble sort, insertion sort, og selection sort. Ang order the akong pag sort kay ascending from gamay to dako ug gi dugang pud nako ang System.nanoTime para ma measure unsa ka pas-pas nag sort ang tulo ka klase sa sort. Sa tulo ka sort ang insertion ang pas-pas sunod kay bubble sort ug selection sort. 

2. Explain how Bubble Sort works.
Ang bubble sort iyang i compare ang duha ka element nga nag abay sulod sa array dayun kung ma identify nga mas greater ang isa kaysa una niya nga element iya dayun ng i swap then balik lang dayun sa uban element sa array hangtod ma sort tanan in ascending order from gamay to dako.

3. Explain how Selection Sort works.
Ang selection sort kay pangitaon niya ang pinaka gamay nga value then i-transfer sa iyang sakto nga order then mangita nasad ug gamay nga value nga sunod ra sa na una niya gi select ganina ug kung kita na sya ug gamay nga element nga wala pa niya na human ug check ang tibook array iya ng i mark nga value.

4. Explain how Insertion Sort works.
Ang insertion sort kay mag kuhag isa ka element sa array ug i butang sa sakto nga position sa elemnt nga iya ng na sort daan. Magsugod kini sa ikaduhang element sa array ug ikumpara kini sa mga elements nga naa sa wala niini. Kung mas dako ang mga naunang elements, ibalhin nila ang ilang posisyon og usa ka step paingon sa tuo. Dayon, ibutang ang gipili nga element sa iyang saktong posisyon.

5. Discuss the differences between the three sorting algorithms.
Ang kalahian sa tulo ka sorting algorithms bubble sort kay para sa gamay ra nga array kay kung sa dagko na nga array mo hinay iyang pag process ug ga-i compare ang duha ka elementh og i-swap. Selection sort kay mangita sa pinaka gamay nga element sa unsorted part sa array. Insertion sort kay mag kuhag isa ka element ug ga i-insert sa sakto nga arrangement.



REFLECTION QUESTIONS:
1. How does each sorting algorithm arrange numbers? What makes their processes different?
Ang Bubble Sort magkumpara sa duha ka magtapad nga numero ug mag-ilis sa ilang posisyon kung ang mas dako nga numero naa sa wala. Ang Selection Sort mangita sa pinakagamay nga numero ug ibutang kini sa saktong posisyon. Samtang ang Insertion Sort magkuha og usa ka numero matag higayon ug ibutang kini sa saktong posisyon taliwala sa mga numero nga nahuman na og sort.

2. Among the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?
Para nako, ang Bubble Sort ang pinakasayon sabton ug i-implement kay simple ra ang iyang proseso. Magkumpara ra siya sa duha ka magtapad nga numero ug mag-ilis sa ilang posisyon kung kinahanglan. Dali ra sab masabtan ang iyang proseso bisan bag-o pa lang nagtuon og sorting algorithms dali rapud tun-an iyang code.

3. If the numbers are already sorted, which algorithm do you think would perform better? Explain your answer based on how the algorithms work.
Para nako, ang Insertion Sort ang mas maayo og performance kung ang mga numero kay nahuman na og sort. Tungod kay sakto na daan ang ilang mga posisyon, dili na kinahanglan nga magbalhin-balhin pa og mga numero. I-compare na lang niya ang mga elements ug dili na kinahanglan og daghang shifting.

4. What will happen if you add more numbers to your array? How might this affect the performance of each sorting algorithm?
Kung magdugang ko og daghang numero sa array, mas modaghan ang elements nga kinahanglan i-compare ug i-sort. Tungod niini, mahimong mas dugay ang execution time sa tulo ka algorithms. Ang Bubble Sort mahimong magkinahanglan og daghang comparisons ug swapping. Ang Selection Sort kinahanglan gihapon mangita sa pinakagamay nga value sa matag pass. Ang Insertion Sort mahimong mas dugay usab kung daghan ang mga numero nga kinahanglan ibalhin sa ilang saktong posisyon.

Isip usa ka future programmer, importante nga masabtan nako ang lain-laing sorting algorithms kay dili tanan sitwasyon parehas. Adunay sorting algorithm nga mas angay gamiton depende sa kadaghan sa data ug sa kahimtang sa mga numero. Makatabang usab kini sa pagpalambo sa akong problem-solving skills ug sa akong kahibalo sa programming.
